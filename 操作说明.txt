============================================
              跟跑助手 - 操作说明
============================================

一款为跑步跟练视频设计的轻量级浏览器工具，支持 B站/YouTube 等网页
视频的全局热键控制、窗口透明度调整、鼠标穿透和悬浮快捷栏。

正式版压缩包内容：
  跟跑助手.exe      主程序，双击运行
  hotkeys.json      默认热键配置，可由软件设置面板自动维护
  操作说明.txt      本说明文件

说明：正式版压缩包不内置浏览器登录数据。首次运行后，软件会在同目录自动
创建 data\ 目录，用来保存 WebView2 的缓存、登录状态和浏览数据。

--------------------------------------------
功能简介
--------------------------------------------

  全局热键        无需聚焦窗口，随时用键盘控制视频播放、快进/退、
                  倍速、透明度等
  悬浮快捷横条    顶部毛玻璃风格横条（播放/快进/网址跳转）
  左侧快捷边栏    80px 窄边栏（穿透/设置），图标与文字上下错行显示
  窗口透明        10 档透明度可调，边跑步边看视频不遮挡其他内容
  鼠标穿透        按 Ctrl+T 切换，鼠标点击穿透窗口直达下层窗口/游戏界面
  即时生效        打开软件后快捷键尽快就绪，无需等视频完全加载
  自动显隐        鼠标离开 3 秒后自动收起，移入恢复
  暗黑主题        内置暗色界面，夜间使用舒适

--------------------------------------------
首次使用
--------------------------------------------

  1. 解压“跟跑浏览器正式版（pc 金金村专用 群号：950610825）.zip”。
  2. 双击运行“跟跑助手.exe”。
  3. 如果系统弹出权限提示，建议选择管理员运行，热键会更稳定。
  4. 默认打开 B站首页；如果需要收藏夹、历史记录等账号内容，请先登录 B站。
  5. 登录状态会保存在软件同目录自动生成的 data\ 目录中。

注意：如果把软件移动到其他文件夹，data\ 目录也一起移动，登录状态才会保留。

--------------------------------------------
悬浮快捷键横条
--------------------------------------------

窗口顶部有一条透明毛玻璃风格的快捷横条，默认隐藏，按 Insert 键呼出/隐藏。

顶部横条按钮（从左到右）：
  [网址输入框] [跳转]  输入视频链接直接跳转（如 bilibili.com/video/xxx）
  [⏯] 播放/暂停      播放或暂停当前视频
  [⏪] 快退            回退 5 秒
  [⏩] 快进            前进 5 秒

左侧边栏按钮（从上到下）：
  [📈] 透明+           提高窗口透明度（更透明）
  [📉] 透明-           降低窗口透明度（更不透明）
  [🔒] 穿透            切换鼠标穿透（红色=关闭/会点到软件，绿色=开启/穿透到下层窗口）
  [⚙] 设置             打开设置面板

横条与边栏联动显隐：
  - 默认隐藏/收起，不占用视频画面
  - 按 Insert 键 → 顶部横条与左侧边栏同时显示/隐藏
  - 鼠标移到网页顶部或左侧边缘 → 双栏同时呼出（3 秒后自动隐藏）
  - 鼠标离开横条或边栏 3 秒 → 双栏同时自动隐藏

响应式适配：
  - 窗口宽度 < 650px：隐藏按钮文字标签，只显示图标
  - 窗口宽度 < 520px：网址输入框缩短
  - 窗口宽度 < 440px：隐藏网址输入框，只保留核心按钮

--------------------------------------------
全局热键一览
--------------------------------------------

所有热键无需窗口处于焦点，在桌面任意位置均可触发。
每次操作均会显示屏幕提示（OSD），确认操作已执行：

  Insert            显示/隐藏横条    呼出或隐藏顶部快捷横条
  Ctrl + Space      播放/暂停        播放或暂停当前视频
  Ctrl + →          快进 5 秒        视频前进 5 秒
  Ctrl + ←          快退 5 秒        视频回退 5 秒
  Ctrl + ↑          透明度+          窗口更透明（10 档循环）
  Ctrl + ↓          透明度-          窗口更不透明
  Home              打开设置         打开热键设置面板
  Ctrl + +(字母区)  倍速+0.25        播放速度加快（通常为 Ctrl+Shift+=）
  Ctrl + -(字母区)  倍速-0.25        播放速度减慢（Ctrl+-）
  Ctrl + 0(字母区)  倍速重置         恢复 1.0 倍速（Ctrl+0）
  Ctrl + Backspace  浏览器后退       网页后退
  Ctrl + T          鼠标穿透         切换鼠标穿透（绿色=穿透/红色=关闭）

透明度档位（按 Ctrl + ↑ / ↓ 循环切换）：

  100% → 90% → 80% → 70% → 60% → 50% → 40% → 30% → 20% → 10% → 100% ...

--------------------------------------------
设置面板
--------------------------------------------

按 Home 键打开设置面板，可自定义以下内容：

  - 启动主页
  - 窗口宽度/高度
  - 透明度级别
  - 是否显示顶部快捷栏
  - 是否自动隐藏快捷栏
  - 每个功能的热键绑定

修改热键方法：
  1. 按 Home 打开设置面板。
  2. 点击对应功能右侧的“修改”。
  3. 按下想要绑定的组合键（如 Ctrl + Space）。
  4. 点击“保存并应用”生效。

新版会检查热键是否属于可注册的 Windows 热键。如果热键格式不支持，设置面板会提示错误。

--------------------------------------------
使用流程示例
--------------------------------------------

  1. 双击运行 跟跑助手.exe。
  2. 默认打开 B站首页，登录后即可访问收藏/历史记录。
  3. 按 Insert 呼出顶部横条，在网址框粘贴视频链接按回车跳转。
  4. 再按 Insert 隐藏横条，视频画面不受遮挡。
  5. 按 Ctrl + ↑ / Ctrl + ↓ 调整窗口透明度。
  6. 开始跑步，全程用键盘控制视频（无需鼠标点击窗口）：
       跑累了想暂停          → Ctrl + Space
       错过了动作讲解        → Ctrl + ← 回退 5 秒
       想快点结束            → Ctrl + Shift + = 加速播放
  7. 窗口盖在其他程序/游戏上，需要点击下层窗口时，按 Ctrl+T 开启鼠标穿透，
     再按 Ctrl+T 关闭穿透恢复跟跑工具操作。

--------------------------------------------
常见问题
--------------------------------------------

Q：为什么有些热键没反应？
A：可能是热键被其他软件（如输入法、截图工具）占用了。
   打开设置面板 (Home)，将该功能重新绑定为其他组合键即可。

Q：透明度调到最低后怎么恢复？
A：继续按 Ctrl + ↓（透明度-），会在 10 个档位间循环，最终会回到 100%。

Q：全屏看视频时透明度还有效吗？
A：有效。透明度调整作用于整个窗口，包括全屏状态。

Q：设置面板打不开？
A：确保没有热键冲突，尝试直接按 Home 键。如果仍无法打开，可关闭程序重新运行。

Q：开启鼠标穿透后点不了横条？
A：这是预期行为。穿透模式下所有鼠标事件都会落到下层窗口。
   需要操作跟跑工具时，按 Ctrl+T 关闭穿透（按钮变红色）即可。

Q：穿透按钮颜色是什么意思？
A：红色 = 穿透关闭，点击会操作到跟跑工具；绿色 = 穿透开启，点击穿透到下层窗口。
   跑步时建议保持绿色，需要操作软件时切回红色。

Q：悬浮横条不显示？
A：横条默认隐藏，按 Insert 键呼出。
   检查设置面板中“显示顶部快捷栏”是否已勾选。
   也可通过热键操作，不依赖横条。

Q：为什么新版压缩包没有 data 文件夹？
A：data 是运行时自动生成的 WebView2 用户数据，可能包含登录状态、Cookie、历史记录。
   为了保护隐私，正式版压缩包不内置 data。首次运行后会自动创建。

Q：软件崩溃了怎么办？
A：请查看同目录下的 debug.log 文件，将最后几行错误信息反馈给开发者。

--------------------------------------------
注意事项
--------------------------------------------

  1. 首次使用建议先登录 B站账号，这样可以直接访问收藏夹和历史记录。
  2. 热键全局生效，在写文档/聊天时也能触发，注意避免设置过于常用的组合键（如 Ctrl + C）。
  3. 窗口透明度较低时，文字可能较难辨认，建议根据环境光线灵活调整。
  4. 软件依赖 WebView2 运行时，Windows 10/11 通常已预装；如无法启动请检查系统更新。
  5. 不建议同时运行多个实例，可能导致热键冲突。
  6. 如果要备份登录状态，请同时备份 exe 同目录下的 data\ 文件夹。
